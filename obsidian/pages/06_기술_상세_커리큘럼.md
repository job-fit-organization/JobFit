# 06. 기술 상세 / 커리큘럼 페이지

## 1. 페이지 목적

선택한 기술의 상세 설명과 단계별 학습 커리큘럼을 제공하는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지:
  - [[04_직무_로드맵]]
  - [[05_기술_목록]]
- 다음 페이지: [[07_학습자료]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 사용자 프로필 |
| 기술 정보 | 기술명, 개요, 활용 분야, 관련 직무 |
| 메타 정보 | 난이도, 예상 학습 시간, 선수 지식 |
| 커리큘럼 표 | Step, 제목, 학습 내용, 키워드, 완료 여부 |
| 관련 기술 | 다음에 학습할 기술 추천 |
| 액션 | 학습자료 보기, 문제 풀기 |

## 4. 사용자 행동

- 기술 설명 확인
- 커리큘럼 Step 선택
- 학습자료 보기 클릭
- 관련 기술 클릭

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| skillId | 기술 ID |
| skillName | 기술명 |
| overview | 기술 개요 |
| relatedJobs | 관련 직무 |
| difficulty | 난이도 |
| prerequisiteSkills | 선수 기술 |
| curriculumId | 커리큘럼 ID |
| stepNumber | Step 번호 |
| completionStatus | 완료 여부 |

## 6. API 메모

### 기술 상세 조회

```http
GET /api/skills/{skillId}
```

### 기술 커리큘럼 조회

```http
GET /api/skills/{skillId}/curriculums?userId={userId}
```

### 응답 예시

```json
{
  "skillId": 1,
  "skillName": "Python",
  "overview": "Python은 데이터 분석, AI 개발, 웹 개발에 활용되는 범용 프로그래밍 언어입니다.",
  "difficulty": "Beginner",
  "estimatedTime": "12h",
  "curriculums": [
    {
      "curriculumId": 101,
      "step": 1,
      "title": "Python 기본 문법",
      "keywords": ["variable", "list", "function"],
      "isCompleted": false
    }
  ]
}
```

## 7. Figma 프롬프트

```text
기술 상세 및 커리큘럼 페이지를 설계해 주세요.
상단에는 기술명과 기술에 대한 상세 설명을 배치합니다.
설명에는 기술 개요, 활용 분야, 관련 직무, 난이도, 예상 학습 시간을 포함해 주세요.
하단에는 단계별 커리큘럼 테이블을 배치합니다.
커리큘럼은 Step 1, Step 2, Step 3 형태이며 각 행에는 제목, 학습 내용, 키워드, 완료 여부, 학습자료 보기 버튼이 포함됩니다.
오른쪽에는 관련 기술 추천 영역을 작게 배치해 주세요.
```
