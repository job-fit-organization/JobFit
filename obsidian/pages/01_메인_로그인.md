# 01. 메인 / 로그인 페이지

## 1. 페이지 목적

서비스를 처음 방문한 사용자가 JobFit의 목적을 이해하고, 소셜 로그인을 통해 서비스를 시작하는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지: 없음
- 다음 페이지: [[02_직무_기술_선택]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 서비스 소개 링크 또는 간단한 설명 |
| Hero | 서비스 핵심 문구, 부제목 |
| Login Box | Google, Kakao, Naver 등 소셜 로그인 버튼 |
| Footer | 이용약관, 개인정보처리방침 |

## 4. 사용자 행동

- 소셜 로그인 버튼 클릭
- 로그인 성공 시 사용자 정보 확인
- 기존 사용자이면 직무/기술 선택 페이지로 이동
- 신규 사용자이면 사용자 정보를 DB에 저장한 뒤 직무/기술 선택 페이지로 이동

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| provider | 소셜 로그인 제공자 |
| social_id | 소셜 계정 고유 ID |
| email | 사용자 이메일 |
| name | 사용자 이름 |
| profile_image | 프로필 이미지 URL, 선택 |

## 6. API 메모

### 로그인 요청

```http
POST /api/auth/social-login
```

### 요청 예시

```json
{
  "provider": "google",
  "accessToken": "SOCIAL_ACCESS_TOKEN"
}
```

### 응답 예시

```json
{
  "userId": 1,
  "email": "user@example.com",
  "name": "User Name",
  "isNewUser": false,
  "accessToken": "SERVICE_ACCESS_TOKEN"
}
```

사용자가 로그인 후 직무/기술 선택 페이지로 이동할 수 있는 구조로 만들어 주세요.
