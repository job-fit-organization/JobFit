# 09. 학습 결과 / 성취도 페이지

## 1. 페이지 목적

문제 풀이 결과를 바탕으로 사용자의 학습 성취도를 보여주는 화면이다.

## 2. 사용자 진입 경로

- 다음 페이지:
  - [[06_기술_상세_커리큘럼]]
  - [[04_직무_로드맵]]
  - [[07_학습자료]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| 결과 요약 | 점수, 정답 수, 오답 수 |
| 성취도 | Progress Bar, Badge, 학습 상태 |
| 오답 리뷰 | 틀린 문제 목록, 정답, 해설 |
| 추천 학습 | 다시 볼 커리큘럼 Step |
| CTA | 다시 풀기, 다음 Step 학습하기, 로드맵으로 돌아가기 |

## 4. 사용자 행동

- 점수 확인
- 오답 해설 확인
- 다시 풀기 클릭
- 다음 Step 학습하기 클릭
- 로드맵으로 돌아가기 클릭

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| userId | 사용자 ID |
| quizId | 퀴즈 ID |
| score | 점수 |
| correctCount | 정답 수 |
| incorrectCount | 오답 수 |
| achievementLevel | 성취도 등급 |
| recommendedCurriculumIds | 복습 추천 커리큘럼 |

## 6. API 메모

### 결과 조회

```http
GET /api/quizzes/{quizId}/result?userId={userId}
```

### 응답 예시

```json
{
  "quizId": 10,
  "score": 80,
  "correctCount": 4,
  "incorrectCount": 1,
  "achievementLevel": "Good",
  "wrongAnswers": [
    {
      "questionId": 1002,
      "questionText": "문제 텍스트",
      "correctAnswer": "정답",
      "explanation": "해설"
    }
  ],
  "recommendations": [
    {
      "curriculumId": 101,
      "title": "Python 기본 문법 복습"
    }
  ]
}
```

## 7. Figma 프롬프트

```text
문제 풀이 결과와 학습 성취도를 보여주는 페이지를 설계해 주세요.
상단에는 총점, 정답 수, 오답 수를 요약 카드로 보여줍니다.
중앙에는 학습 성취도를 Progress Bar와 Badge 형태로 표시합니다.
하단에는 틀린 문제 목록과 해설 다시 보기 영역을 배치합니다.
사용자가 다시 풀기, 다음 Step 학습하기, 로드맵으로 돌아가기 중 하나를 선택할 수 있도록 버튼을 배치해 주세요.
```
