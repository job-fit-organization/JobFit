# 05. 기술 목록 페이지

## 1. 페이지 목적

사용자가 특정 직무와 무관하게 기술을 직접 탐색하고 선택하는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지: [[02_직무_기술_선택]]
- 다음 페이지: [[06_기술_상세_커리큘럼]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 사용자 프로필 |
| 제목 | “학습할 기술을 선택해 주세요” |
| 검색 | 기술명 검색창 |
| 사이드바 | 분야, 난이도, 관련 직무, 학습 시간 필터 |
| 정렬 | 추천순, 인기순, 최신순 |
| 기술 카드 | 기술명, 설명, 관련 직무, 난이도, 학습 시작 버튼 |

## 4. 사용자 행동

- 기술 검색
- 필터 적용
- 정렬 기준 변경
- 기술 카드 클릭
- 기술 상세 페이지로 이동

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| skillId | 기술 ID |
| skillName | 기술명 |
| description | 기술 요약 설명 |
| category | 기술 분야 |
| difficulty | 난이도 |
| relatedJobs | 관련 직무 목록 |
| estimatedTime | 예상 학습 시간 |

## 6. API 메모

### 기술 목록 조회

```http
GET /api/skills?keyword={keyword}&category={category}&difficulty={difficulty}&sort={sort}
```

### 응답 예시

```json
[
  {
    "skillId": 1,
    "skillName": "Python",
    "description": "데이터 분석과 AI 개발에 널리 사용되는 프로그래밍 언어",
    "category": "Programming",
    "difficulty": "Beginner",
    "relatedJobs": ["Data Scientist", "AI Agent Developer"],
    "estimatedTime": "12h"
  }
]
```

## 7. Figma 프롬프트

```text
사용자가 학습할 기술을 직접 선택하는 기술 목록 페이지를 설계해 주세요.
상단에는 “학습할 기술을 선택해 주세요”라는 제목과 기술 검색창을 배치합니다.
좌측에는 필터링 사이드바를 배치해 주세요.
필터 항목은 분야, 난이도, 관련 직무, 학습 시간, 추천순입니다.
오른쪽 메인 영역에는 기술 카드들을 그리드 형태로 배치합니다.
각 카드에는 기술명, 간단한 설명, 관련 직무, 난이도, 학습 시작 버튼을 포함해 주세요.
```
