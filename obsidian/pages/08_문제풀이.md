# 08. 문제 풀이 페이지

## 1. 페이지 목적

학습자가 커리큘럼 학습 후 문제를 풀고 이해도를 확인하는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지: [[07_학습자료]]
- 다음 페이지: [[09_학습결과]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 기술명, Step명, 문제 진행률 |
| 문제 영역 | 문제 번호, 문제 텍스트 |
| 선택지 영역 | 객관식 선택지, 라디오 버튼 |
| 하단 버튼 | 이전 문제, 다음 문제, 답변 제출 |
| 결과 영역 | 정답 여부, 해설 |

## 4. 사용자 행동

- 선택지 선택
- 답변 제출
- 다음 문제로 이동
- 모든 문제 제출 후 결과 페이지로 이동

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| quizId | 퀴즈 ID |
| questionId | 문제 ID |
| questionText | 문제 텍스트 |
| optionId | 선택지 ID |
| optionText | 선택지 텍스트 |
| selectedOptionId | 사용자가 선택한 선택지 |
| explanation | 해설 |

## 6. API 메모

### 문제 목록 조회

```http
GET /api/curriculums/{curriculumId}/quizzes
```

### 답변 제출

```http
POST /api/quizzes/{quizId}/submit
```

```json
{
  "userId": 1,
  "answers": [
    {
      "questionId": 1001,
      "selectedOptionId": 3
    }
  ]
}
```

### 응답 예시

```json
{
  "quizId": 10,
  "score": 80,
  "correctCount": 4,
  "totalCount": 5,
  "results": [
    {
      "questionId": 1001,
      "isCorrect": true,
      "correctOptionId": 3,
      "explanation": "정답 해설입니다."
    }
  ]
}
```

## 7. Figma 프롬프트

```text
학습 후 문제 풀이 페이지를 설계해 주세요.
상단에는 현재 기술명, 커리큘럼 Step명, 문제 진행률을 표시합니다.
중앙에는 문제 텍스트를 크게 보여주고, 아래에는 객관식 선택지를 라디오 버튼 형태로 배치합니다.
하단에는 이전 문제, 다음 문제, 답변 제출 버튼을 배치합니다.
답변 제출 후에는 정답 여부와 해설이 표시될 수 있는 결과 영역도 포함해 주세요.
```
