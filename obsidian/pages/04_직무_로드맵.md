# 04. 직무 기반 기술 로드맵 페이지

## 1. 페이지 목적

사용자가 선택한 직무에 필요한 기술을 로드맵 형태로 보여주는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지: [[03_직무_선택]]
- 다음 페이지: [[06_기술_상세_커리큘럼]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 사용자 프로필 |
| 직무 정보 | 선택한 직무명, 직무 설명 |
| 로드맵 영역 | 기술 노드, 연결선, 학습 순서 |
| 기술 노드 | Python, SQL, Pandas, ML, GitHub, Docker, Linux, AWS 등 |
| 상태 표시 | 미시작, 진행 중, 완료 |
| 액션 | 기술 상세 보기, 커리큘럼 시작하기 |

## 4. 사용자 행동

- 로드맵에서 기술 노드 클릭
- 기술 상세 페이지로 이동
- 학습 완료 상태 확인

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| jobId | 선택한 직무 ID |
| skillId | 기술 ID |
| skillName | 기술명 |
| prerequisiteSkillIds | 선수 기술 ID 목록 |
| learningOrder | 학습 순서 |
| progressStatus | 사용자별 학습 상태 |

## 6. API 메모

### 직무별 기술 로드맵 조회

```http
GET /api/jobs/{jobId}/roadmap?userId={userId}
```

### 응답 예시

```json
{
  "jobId": 1,
  "jobName": "Data Scientist",
  "skills": [
    {
      "skillId": 1,
      "skillName": "Python",
      "level": "beginner",
      "status": "completed",
      "nextSkillIds": [2, 3]
    },
    {
      "skillId": 2,
      "skillName": "Pandas",
      "level": "beginner",
      "status": "in_progress",
      "nextSkillIds": [4]
    }
  ]
}
```

## 7. Figma 프롬프트

```text
선택한 직무에 필요한 기술 로드맵 페이지를 설계해 주세요.
상단에는 선택한 직무명과 간단한 설명을 보여줍니다.
중앙에는 기술 로드맵을 노드와 연결선 형태로 표현해 주세요.
예시 노드는 Python, SQL, Pandas, Visualization, Machine Learning, GitHub, Docker, Linux, AWS입니다.
각 노드는 학습 상태를 나타낼 수 있도록 미시작, 진행 중, 완료 상태 표시 영역을 포함합니다.
사용자가 노드를 클릭하면 기술 상세 페이지로 이동하는 구조로 설계해 주세요.
```
