# 03. 직무 선택 페이지

## 1. 페이지 목적

사용자가 관심 있는 직무를 선택하는 화면이다. 선택한 직무를 기준으로 필요한 기술 로드맵을 제공한다.

## 2. 사용자 진입 경로

- 이전 페이지: [[02_직무_기술_선택]]
- 다음 페이지: [[04_직무_로드맵]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 사용자 프로필 |
| 제목 | “관심 있는 직무를 선택해 주세요” |
| 검색 영역 | 직무명 검색창 |
| 필터 영역 | 분야별 직무 필터 |
| 직무 카드 | AI Agent, Data Scientist, Backend Developer, Data Analyst 등 |
| 예외 카드 | “아직 잘 모르겠어요” |
| CTA | 선택 완료, 로드맵 보기 |

## 4. 사용자 행동

- 직무 검색
- 직무 카드 선택
- 선택 완료 버튼 클릭
- 선택 직무의 기술 로드맵으로 이동

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| jobId | 직무 ID |
| jobName | 직무명 |
| jobDescription | 직무 설명 |
| category | 직무 분야 |
| requiredSkillCount | 필요 기술 수 |

## 6. API 메모

### 직무 목록 조회

```http
GET /api/jobs
```

### 응답 예시

```json
[
  {
    "jobId": 1,
    "jobName": "AI Agent Developer",
    "description": "AI Agent 서비스를 설계하고 구현하는 직무",
    "category": "AI",
    "requiredSkillCount": 8
  }
]
```

### 사용자 직무 선택 저장

```http
POST /api/users/{userId}/selected-job
```

```json
{
  "jobId": 1
}
```

## 7. Figma 프롬프트

```text
사용자가 관심 있는 직무를 선택하는 페이지를 설계해 주세요.
상단에는 “관심 있는 직무를 선택해 주세요”라는 안내 문구를 배치합니다.
중앙에는 직무 카드 목록을 그리드 형태로 배치해 주세요.
예시 직무는 AI Agent, Data Scientist, Backend Developer, Data Analyst, Frontend Developer입니다.
카드 하단에는 간단한 설명을 넣고, 사용자가 아직 직무를 모르는 경우를 위한 “잘 모르겠어요” 카드도 포함해 주세요.
상단 또는 좌측에는 직무 검색창과 분야 필터를 배치해 주세요.
```
