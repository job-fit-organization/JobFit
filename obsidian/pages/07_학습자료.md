# 07. 학습자료 렌더링 페이지

## 1. 페이지 목적

선택한 커리큘럼 Step에 해당하는 학습자료를 보여주는 화면이다.

## 2. 사용자 진입 경로

- 이전 페이지: [[06_기술_상세_커리큘럼]]
- 다음 페이지: [[08_문제풀이]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 기술명, Step 제목 |
| 사이드바 | 커리큘럼 목차, 이전/다음 Step |
| 본문 | 학습자료 렌더링 영역 |
| 콘텐츠 블록 | 텍스트, 이미지, 코드 블록, 표 |
| 진행 상태 | 학습 진행률 |
| 하단 버튼 | 커리큘럼으로 돌아가기, 문제 풀러가기 |
| 보조 기능 | 북마크, 메모, 이해도 체크 |

## 4. 사용자 행동

- 학습자료 읽기
- 목차에서 다른 Step 선택
- 커리큘럼으로 돌아가기
- 문제 풀러가기 클릭

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| curriculumId | 커리큘럼 ID |
| skillId | 기술 ID |
| title | 학습자료 제목 |
| content | 렌더링할 학습자료 본문 |
| contentType | markdown, html 등 |
| progress | 학습 진행률 |

## 6. API 메모

### 학습자료 조회

```http
GET /api/curriculums/{curriculumId}/material?userId={userId}
```

### 학습 진행 상태 저장

```http
POST /api/users/{userId}/learning-progress
```

```json
{
  "curriculumId": 101,
  "progress": 100,
  "status": "completed"
}
```

## 7. Figma 프롬프트

```text
커리큘럼 학습자료 렌더링 페이지를 설계해 주세요.
상단에는 현재 학습 중인 기술명과 커리큘럼 Step 제목을 표시합니다.
왼쪽에는 커리큘럼 목차 사이드바를 배치하고, 중앙에는 학습자료 본문을 크게 배치합니다.
본문은 텍스트, 코드 블록, 이미지 영역이 포함될 수 있도록 구성해 주세요.
하단에는 “커리큘럼으로 돌아가기” 버튼과 “문제 풀러가기” 버튼을 배치합니다.
학습 진행률을 표시하는 작은 Progress Bar도 포함해 주세요.
```
