# 02. 직무 / 기술 선택 페이지

## 1. 페이지 목적

로그인한 사용자가 학습을 시작할 기준을 선택하는 화면이다. 사용자는 직무 기반 탐색 또는 기술 기반 탐색 중 하나를 선택한다.

## 2. 사용자 진입 경로

- 이전 페이지: [[01_메인_로그인]]
- 다음 페이지:
  - 직무 선택 시: [[03_직무_선택]]
  - 기술 선택 시: [[05_기술_목록]]

## 3. 주요 화면 요소

| 영역 | 구성 요소 |
|---|---|
| Header | 서비스명, 사용자 프로필 |
| 안내 문구 | “무엇을 기준으로 학습을 시작할까요?” |
| 선택 카드 | 직무로 시작하기, 기술로 시작하기 |
| 설명 문구 | 각 선택 방식의 차이 설명 |

## 4. 사용자 행동

- `직무로 시작하기` 클릭 → 직무 선택 페이지로 이동
- `기술로 시작하기` 클릭 → 기술 목록 페이지로 이동

## 5. 필요한 데이터

| 데이터 | 설명 |
|---|---|
| userId | 로그인한 사용자 ID |
| selectedMode | job 또는 skill |

## 6. API 메모

선택 모드를 저장하려면 아래 API를 사용할 수 있다.

```http
POST /api/users/{userId}/start-mode
```

```json
{
  "selectedMode": "job"
}
```

단순 화면 이동만 필요한 경우 API 호출 없이 프론트엔드 라우팅으로 처리해도 된다.

## 7. Figma 프롬프트

```text
로그인 후 사용자가 학습 시작 방식을 선택하는 페이지를 설계해 주세요.
중앙에는 두 개의 큰 선택 카드가 있습니다.
첫 번째 카드는 “직무로 시작하기”, 두 번째 카드는 “기술로 시작하기”입니다.
각 카드에는 간단한 설명과 아이콘 영역을 포함해 주세요.
사용자가 카드를 클릭하면 다음 페이지로 이동하는 구조로 표현해 주세요.
```
