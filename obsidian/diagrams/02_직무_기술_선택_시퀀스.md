# 02. 직무/기술 선택 시퀀스

## 목적

로그인한 사용자가 학습 탐색 방식을 `직무 기반` 또는 `기술 기반` 중 하나로 선택하고, 선택 결과에 따라 다음 화면으로 분기되는 흐름을 표현한다.

## 참여 객체

| 객체 | 역할 |
|---|---|
| 사용자 | 직무 또는 기술 탐색 방식을 선택 |
| Web Client | 선택지를 표시하고 선택 결과를 서버로 전송 |
| Preference API | 사용자의 시작 방식 선택을 저장 |
| Database | 사용자 선택 정보 저장 |

## Mermaid 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor User as 사용자
    participant Client as Web Client
    participant PreferenceAPI as Preference API
    participant DB as Database

    User->>Client: 직무로 시작하기 또는 기술로 시작하기 선택
    Client->>PreferenceAPI: 시작 방식 저장 요청 (Header: Token) {selectedType}

    PreferenceAPI->>DB: 사용자 선택 정보 저장
    DB-->>PreferenceAPI: 저장 완료

    alt 직무 기반 선택
        PreferenceAPI-->>Client: 다음 화면 정보 반환 {nextPage: "job-selection"}
        Client-->>User: 직무 선택 페이지 표시
    else 기술 기반 선택
        PreferenceAPI-->>Client: 다음 화면 정보 반환 {nextPage: "skill-list"}
        Client-->>User: 기술 목록 페이지 표시
    end
```

## API 메모

### POST /api/users/me/preference

#### Request

```json
{
  "selectedType": "JOB"
}
```

#### Response

```json
{
  "userId": 1,
  "selectedType": "JOB",
  "nextPage": "job-selection"
}
```

## 예외 상황

| 상황 | 처리 |

| 로그인 세션 만료 | 로그인 페이지로 이동 |
