# 08. 학습결과 및 성취도 조회 시퀀스

## 목적

문제 풀이가 끝난 뒤 사용자의 점수, 정답 수, 오답 수, 커리큘럼 완료율, 복습 추천 항목을 조회하여 학습 결과 화면에 표시하는 흐름을 표현한다.

## 참여 객체

| 객체 | 역할 |
|---|---|
| 사용자 | 학습 결과와 추천 복습 항목 확인 |
| Web Client | 점수, 완료율, 오답 목록, 추천 Step 표시 |
| Progress API | 사용자 학습 성취도 조회 |
| Database | 학습 이력, 풀이 결과, 커리큘럼 완료 상태 저장 |

## Mermaid 시퀀스 다이어그램

```mermaid
sequenceDiagram
    actor User as 사용자
    participant Client as Web Client
    participant ProgressAPI as Progress API
    participant DB as Database

    User->>Client: 학습 결과 페이지 진입
    Client->>ProgressAPI: 학습 성취도 조회 요청 (Header: Token) {skillId, curriculumId}

    ProgressAPI->>DB: 사용자 문제 풀이 결과 조회
    DB-->>ProgressAPI: 점수, 정답 수, 오답 수 반환

    ProgressAPI->>DB: 커리큘럼 완료 상태 조회
    DB-->>ProgressAPI: 완료 Step, 전체 Step 반환

    ProgressAPI->>DB: 오답 기반 복습 추천 항목 조회
    DB-->>ProgressAPI: 복습 Step 및 오답 문제 반환

    ProgressAPI-->>Client: 성취도 데이터 응답 {score, progressRate, wrongAnswers, recommendedSteps}
    Client-->>User: 학습 결과 및 복습 추천 화면 표시

    alt 다시 풀기 선택
        User->>Client: 다시 풀기 클릭
        Client-->>User: 문제 풀이 페이지로 이동
    else 다음 Step 학습 선택
        User->>Client: 다음 Step 학습하기 클릭
        Client-->>User: 다음 학습자료 페이지로 이동
    else 로드맵으로 돌아가기 선택
        User->>Client: 로드맵으로 돌아가기 클릭
        Client-->>User: 직무 로드맵 페이지로 이동
    end
```

## API 메모

### GET /api/users/me/progress

#### Query Parameters

```text
skillId=1
curriculumId=1
```

#### Response

```json
{
  "userId": 1,
  "skillId": 1,
  "curriculumId": 1,
  "score": 80,
  "correctCount": 4,
  "wrongCount": 1,
  "progressRate": 60,
  "wrongAnswers": [
    {
      "quizId": 3,
      "question": "반복문에 대한 설명 중 틀린 것은?",
      "explanation": "for문과 while문은 반복 조건을 처리하는 방식이 다릅니다."
    }
  ],
  "recommendedSteps": [
    {
      "curriculumId": 2,
      "title": "Python 반복문 심화"
    }
  ]
}
```

## 예외 상황

| 상황 | 처리 |
|---|---|
| 학습 결과 없음 | 기본 상태 또는 학습 시작 안내 표시 |
| 오답 없음 | “모든 문제를 맞혔습니다” 표시 |
| 추천 항목 없음 | 다음 Step 학습 버튼 표시 |
