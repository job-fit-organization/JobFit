# JobFit Prototype Folder

이 폴더는 JobFit의 Figma 기반 화면을 HTML/CSS/JavaScript 정적 프로토타입으로 관리하기 위한 Obsidian 문서와 소스 파일을 포함합니다.

## 폴더 구조

```text
prototype/
├── 00_프로토타입_관리.md
├── 01_HTML_구조.md
├── 02_CSS_스타일_가이드.md
├── 03_JavaScript_화면전환_로직.md
├── 04_API_연동_전환_계획.md
└── source/
    ├── index.html
    ├── styles.css
    └── app.js
```

## 사용 방법

기존 Obsidian Vault의 루트 폴더에 `prototype` 폴더를 복사합니다.
그 후 `prototype/source/index.html`을 브라우저에서 실행하면 정적 프로토타입을 확인할 수 있습니다.
