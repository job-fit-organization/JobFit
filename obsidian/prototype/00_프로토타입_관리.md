# 00. HTML/CSS/JavaScript 프로토타입 관리

## 목적

이 문서는 Figma 화면 설계를 바탕으로 작성한 JobFit 정적 웹 프로토타입을 Obsidian에서 함께 관리하기 위한 문서입니다.

## 관련 소스 파일

- [[source/index.html]]
- [[source/styles.css]]
- [[source/app.js]]

## 포함 화면

```text
메인 / 로그인
→ 직무·기술 선택
→ 직무 선택
→ 직무 상세 설명
→ 직무 기반 로드맵
→ 기술 상세 / 커리큘럼
→ 학습자료
→ 문제 풀이
→ 학습 결과
```

기술로 시작하는 흐름도 함께 포함합니다.

```text
기술 선택
→ 기술 상세 / 커리큘럼
→ 학습자료
→ 문제 풀이
→ 학습 결과
```

## 실행 방법

1. `prototype/source` 폴더를 연다.
2. `index.html` 파일을 브라우저에서 실행한다.
3. 버튼과 카드를 클릭하면서 화면 전환을 확인한다.

## 관리 원칙

- 화면 구조는 `index.html`의 `<template>` 단위로 관리한다.
- 스타일은 `styles.css`에서 공통 디자인 토큰과 컴포넌트 단위로 관리한다.
- 화면 전환, 예시 데이터, 이벤트 처리는 `app.js`에서 관리한다.
- 실제 API 연동 전까지는 `app.js`의 배열 데이터를 목업 데이터로 사용한다.
