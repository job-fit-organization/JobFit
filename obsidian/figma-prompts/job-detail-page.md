# Figma Prompt: Job Detail Page

## 페이지명

직무 상세 설명 페이지

## Figma Wireframe Designer 프롬프트

```text
JobFit 서비스의 직무 상세 설명 페이지를 설계해 주세요.

이 화면은 사용자가 직무 선택 페이지에서 특정 직무 카드를 클릭한 뒤 진입하는 화면입니다.
사용자는 이 화면에서 직무의 특징, 실제 업무, 주로 사용하는 기술 스택, 장점과 단점을 확인한 뒤 해당 직무의 학습 로드맵으로 이동할 수 있어야 합니다.

화면 상단에는 서비스명, 뒤로가기 버튼, 사용자 메뉴를 배치해 주세요.

본문 첫 영역에는 선택한 직무명을 크게 표시하고, 그 아래에 직무 한 줄 요약과 대표 태그를 배치해 주세요.
예시 직무명은 “AI Agent Developer”입니다.
예시 태그는 #LLM, #RAG, #LangChain, #Backend, #Automation입니다.

두 번째 영역에는 “직무 특징” 섹션을 카드 형태로 구성해 주세요.
각 카드에는 짧은 제목과 설명을 넣을 수 있도록 해 주세요.

세 번째 영역에는 “실제 업무” 섹션을 배치해 주세요.
업무는 리스트 형태로 보여주세요.
예시는 사용자 요구사항 분석, Agent workflow 설계, LLM 및 RAG 기반 기능 구현, API 및 DB 연동, 응답 품질 평가입니다.

네 번째 영역에는 “주로 사용하는 기술 스택” 섹션을 배치해 주세요.
기술 스택은 태그 또는 작은 카드 형태로 보여주세요.
예시는 Python, LangChain, FastAPI, PostgreSQL, Vector DB, Docker, AWS, GitHub입니다.

다섯 번째 영역에는 “장점”과 “단점”을 2열 카드로 나누어 보여주세요.
장점은 최신 AI 기술 활용, 다양한 산업 적용, 서비스 구현 경험 축적입니다.
단점은 빠른 기술 변화, 평가 기준 설계 어려움, 데이터 품질 영향입니다.

하단에는 두 개의 CTA 버튼을 배치해 주세요.
왼쪽 버튼은 “다른 직무 보기”, 오른쪽 강조 버튼은 “이 직무 로드맵 보기”입니다.

전체 화면은 교육 플랫폼과 커리어 탐색 서비스의 중간 느낌으로, 깔끔하고 정보 구조가 명확한 와이어프레임으로 구성해 주세요.
```
