# 페이지 및 뷰(View) 목록 (v2 - Django 통합 풀스택)

본 문서는 **JobFit**의 전체 화면 매핑 정보 및 장고(Django) 뷰 아키텍처 규칙을 정의합니다.

---

## 1. 9대 핵심 화면 및 뷰 매핑 사양

Django 풀스택 구조로의 통합에 따라 별도의 REST API 대신, 장고 뷰(View)가 각 화면에 매핑된 URL 요청을 직접 처리하여 템플릿(HTML)을 동적으로 채워 렌더링합니다.

| 번호 | 화면명 (UI) | URL 패턴 (Route) | 장고 뷰 명칭 (Django View) | 매핑 템플릿 파일 | 핵심 연동 목적 |
|---|---|---|---|---|---|
| **01** | [메인 / 로그인](pages/01_메인_로그인.md) | `/` | `LandingView` | `landing.html` | 서비스 비주얼 소개 및 소셜 로그인 버튼 노출 |
| **02** | [직무 / 기술 선택](pages/02_직무_기술_선택.md) | `/select-mode/` | `SelectModeView` | `mode_select.html` | 학습 모드 분기 (직무 탐색 vs 기술 직접 탐색) |
| **03** | [직무 선택](pages/03_직무_선택.md) | `/jobs/` | `JobListView` | `job_select.html` | 관심 직무 리스트 검색/필터 및 등록 처리 |
| **04** | [직무 기반 기술 로드맵](pages/04_직무_로드맵.md) | `/jobs/<int:job_id>/roadmap/` | `JobRoadmapView` | `job_roadmap.html` | 다중 시작점(Python/SQL) 및 DAG 형태의 시각 로드맵 드로잉 |
| **05** | [기술 목록](pages/05_기술_목록.md) | `/skills/` | `SkillListView` | `skill_list.html` | 분야, 난이도별 필터를 통한 전체 기술 직접 검색 |
| **06** | [기술 상세 / 커리큘럼](pages/06_기술_상세_커리큘럼.md) | `/skills/<int:skill_id>/` | `SkillDetailView` | `skill_detail.html` | 개요 제공 및 단계별(Step 1~4) 커리큘럼 이력 렌더링 |
| **07** | [학습자료 렌더링](pages/07_학습자료.md) | `/curriculums/<int:curr_id>/material/` | `MaterialView` | `learning_material.html` | 마크다운 포맷 학습 리소스 렌더링 및 실시간 진도율 갱신 |
| **08** | [문제 풀이](pages/08_문제풀이.md) | `/curriculums/<int:curr_id>/quiz/` | `QuizPlayView` | `quiz_play.html` | 4지선다 퀴즈 인터랙티브 풀이 및 세션 상태 관리 |
| **09** | [학습 결과 / 성취도](pages/09_학습결과.md) | `/quiz/attempts/<int:attempt_id>/result/` | `QuizResultView` | `quiz_result.html` | 퀴즈 채점 결과 요약, 오답 노트 리포트 및 복습 추천 |
| **10** | 로그아웃 처리 | `/logout/` | `LogoutView` | 없음 (리다이렉트) | 로그인 세션 파괴 및 메인 랜딩(landing) 화면 이동 |
| **11** | 관심 직무 초기화 | `/jobs/reset/` | `JobResetView` | 없음 (리다이렉트) | 기존 관심 직무 선택 정보 삭제 및 직무 선택(job_select) 화면 이동 |

---

## 2. 템플릿 및 정적 리소스(Static) 상속 구조

`obsidian/prototype/source/` 의 훌륭한 디자인 패턴을 상속하여 극도로 정갈하고 시각적으로 완성도 높은 템플릿 아키텍처를 구현합니다.

```
backend/
 ├── static/
 │    ├── css/
 │    │    └── styles.css        <-- 프로토타입의 CSS를 이식한 핵심 프리미엄 스타일시트
 │    ├── js/
 │    │    ├── app.js            <-- 프로토타입의 라우팅을 제외한 화면 효과 및 SVG 로드맵 드로잉 엔진
 │    │    └── lucide.min.js     <-- SVG 라인 아이콘 렌더링 엔진
 │    └── images/
 │         └── jobs/             <-- AI 이미지 생성 툴로 제작한 프리미엄 직무 일러스트 에셋 (.png)
 └── templates/
      ├── base.html              <-- 공통 헤더, 푸터, Lucide 로드, 공통 디자인 시스템 토큰 적용 레이아웃
      ├── landing.html
      ├── mode_select.html
      ├── job_select.html
      ├── job_roadmap.html
      ├── skill_list.html
      ├── skill_detail.html
      ├── learning_material.html
      ├── quiz_play.html
      └── quiz_result.html
```

### 💡 템플릿 상속 예시 (`landing.html`)

```html
{% load static %}

{% block title %}나에게 딱 맞는 AI 커리어 빌더 - JobFit{% endblock %}

    <div class="inline-block px-6 py-2 rounded-full bg-[#f47725]/10 text-[#f47725] text-xs font-bold mb-6 tracking-widest uppercase">
        Empowering Your AI Career
    </div>
    ...
</section>
{% endblock %}
```
