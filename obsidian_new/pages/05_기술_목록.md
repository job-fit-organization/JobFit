## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/skills/`
*   **장고 뷰 명칭:** `SkillListView`
*   **매핑 템플릿:** `skill_list.html`
*   **Context 데이터:**
    *   `skills`: 검색 및 필터 파라미터가 쿼리셋 필터링을 통해 계산된 `Skill` 레코드 리스트
*   **검색 및 필터링 질의 연동 (GET Query String):**
    ```python
    def get_queryset(self):
        queryset = Skill.objects.all()
        keyword = self.request.GET.get('keyword')
        category = self.request.GET.get('category')
        level = self.request.GET.get('level')
        
        if keyword:
            queryset = queryset.filter(Q(skill_name__icontains=keyword) | Q(skill_desc__icontains=keyword))
        if category:
            queryset = queryset.filter(skill_code__istartswith=category) # 코드로 분류 처리
        if level:
            queryset = queryset.filter(skill_level=level)
            
        return queryset
    ```
