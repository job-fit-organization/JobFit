## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/curriculums/<int:curr_id>/material/`
*   **장고 뷰 명칭:** `MaterialView`
*   **매핑 템플릿:** `learning_material.html`
*   **Context 데이터:**
    *   `curriculum`: 상세 열람 중인 `Curriculum` 레코드
    *   `html_content`: `markdown` 모듈 등을 활용해 마크다운 본문을 HTML로 최종 변환한 데이터 (XSS 우회 필터링 안전 적용)
    *   `is_bookmarked`: 현재 사용자가 본 단원을 북마크했는지 여부 (`True` / `False`)
    *   `user_note`: 현재 사용자가 본 단원에 작성해 둔 기존 메모 텍스트 (`UserNote` 레코드)
*   **학습 시작 세션 상태 자동 영속화:**
    *   `MaterialView`의 `get()` 메소드가 실행되면, 백엔드 내부적으로 `UserCurriculumProgress` 레코드를 자동 생성하거나 상태를 업데이트합니다.
    ```python
    # 진도 상태 자동 업데이트
    progress, created = UserCurriculumProgress.objects.get_or_create(
        user_profile=request.user.userprofile,
        curriculum_id=curr_id,
        defaults={'status': 'in_progress', 'progress': 50} # 자료 열람 시 기본 50% 부여
    )
    ```
    *   **선행 학습 잠금 검증 (TC-LOCK-01 방어 설계):**
        *   `MaterialView` 역시 진입 즉시 선행 잠금 유효성 검사를 실행합니다.
        *   해당 커리큘럼 단원이 속한 기술의 선행 기술들이 이수 완료(`completed`)되지 않았다면, 자료 열람 주소창 직접 호출 시 즉각 진입 차단 및 경고를 띄운 후 로드맵으로 리다이렉트합니다.

## 5. 북마크 및 메모 저장 비즈니스 로직 (POST)

### ① 북마크 토글 뷰 (`/curriculums/<int:curr_id>/bookmark/`)
*   **메소드:** `POST` (AJAX 호출 또는 폼 제출)
*   **동작:**
    ```python
    bookmark_qs = UserBookmark.objects.filter(user_profile=user_profile, curriculum_id=curr_id)
    if bookmark_qs.exists():
        bookmark_qs.delete()
        is_bookmarked = False
    else:
        UserBookmark.objects.create(user_profile=user_profile, curriculum_id=curr_id)
        is_bookmarked = True
    return JsonResponse({'is_bookmarked': is_bookmarked})
    ```

### ② 개인 메모 저장 뷰 (`/curriculums/<int:curr_id>/note/`)
*   **메소드:** `POST`
*   **동작:**
    ```python
    note_text = request.POST.get('note_text', '').strip()
    note, created = UserNote.objects.update_or_create(
        user_profile=user_profile,
        curriculum_id=curr_id,
        defaults={'note_text': note_text}
    )
    return JsonResponse({'status': 'success', 'updated_at': note.updated_at})
    ```
