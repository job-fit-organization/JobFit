## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/quiz/attempts/<int:attempt_id>/result/`
*   **장고 뷰 명칭:** `QuizResultView`
*   **매핑 템플릿:** `quiz_result.html`
*   **Context 데이터:**
    *   `attempt`: 해당 `QuizAttempt` 레코드
    *   `wrong_responses`: 틀린 문제 리스트 (문제 내용, 사용자가 제출한 값, 정답 값, 해설 데이터가 패킹됨)
    *   `recommended_review_step`: 70점 미만 낙제 시, 복습을 위해 바로 진입해야 하는 `Curriculum` 정보 주입
        ```python
        # 백엔드 오답 패킹 예시
        user_responses = UserResponse.objects.filter(quiz_attempt_id=attempt_id)
        wrong_responses = []
        
        for resp in user_responses:
            if not resp.is_correct:
                correct_choice = QuizChoice.objects.get(question=resp.question, is_correct=True)
                wrong_responses.append({
                    'question_text': resp.question.question_text,
                    'user_selected_text': resp.selected_choice.choice_text,
                    'correct_text': correct_choice.choice_text,
                    'explanation': resp.selected_choice.explanation # 오답에 매핑된 해설
                })
        ```
