## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/curriculums/<int:curr_id>/quiz/`
*   **장고 뷰 명칭:** `QuizPlayView`
*   **매핑 템플릿:** `quiz_play.html`
*   **Context 데이터:**
    *   `curriculum`: 매핑된 단원 레코드
    *   `questions`: DB로부터 아래 규칙에 따라 동적으로 랜덤 추출된 **총 5개**의 퀴즈 문항 목록
        *   **쉬움 (Difficulty = 'Easy'):** 2개 문항 무작위 추출 (`order_by('?')[:2]`)
        *   **중간 (Difficulty = 'Medium'):** 2개 문항 무작위 추출 (`order_by('?')[:2]`)
        *   **어려움 (Difficulty = 'Hard'):** 1개 문항 무작위 추출 (`order_by('?')[:1]`)
    *   **선택지 무작위 셔플링 (Random Shuffling):**
        *   의도된 설계에 따라 `QuizChoice` 테이블에는 고정 순서(`choice_no`) 컬럼이 존재하지 않습니다.
        *   사용자가 특정 답안의 번호나 정답 위치를 암기하여 풀이하는 편법을 원천 차단하기 위해, 각 문항에 종속된 4개의 선택지는 화면에 드로잉될 때마다 **데이터베이스 쿼리 레벨에서 무작위로 섞여 렌더링**됩니다. (Django ORM 예시: `question.choices.order_by('?')`)
    *   **문항 부족 상황 예외 처리 (TC-QUIZ-01 방어 설계):**
        *   DB에 등록된 해당 커리큘럼 단원의 문항 수가 부족하여 `쉬움 2개, 중간 2개, 어려움 1개` 조합을 완벽히 충족하지 못하는 경우, 시스템 크래시나 점수 꼬임 방지를 위해 퀴즈 진입을 **안전 차단**합니다.
        *   사용자에게 "학습 평가 문항 수가 아직 충분치 않습니다. 관리자에게 문의하세요."라는 정중한 안내 메시지를 경고 배너로 노출하며 **[04. 직무 로드맵]** 화면으로 안전하게 리다이렉트시킵니다.

### 📊 퀴즈 배점 및 합격 기준
| 문제 난이도 | 추출 문항 수 | 문항당 배점 | 총점 |
|---|---|---|---|
| **쉬움 (Easy)** | 2개 | 15점 | 30점 |
| **중간 (Medium)** | 2개 | 20점 | 40점 |
| **어려움 (Hard)** | 1개 | 30점 | 30점 |
| **합계** | **5개** | - | **100점** |

*   **합격 통과 기준:** **70점 이상** (마스터리 획득 및 커리큘럼 완료 처리)

---

*   **POST 요청 처리 (채점 및 오답 이력 영속화):**
    *   사용자가 퀴즈를 모두 풀고 최종 제출 버튼을 클릭하면, 각 문제와 선택한 답변이 장고 뷰로 POST 제출됩니다.
    *   **중복 제출 및 뒤로가기 우회 방지 (TC-QUIZ-02 방어 설계):**
        *   제출 완료 플래그 혹은 고유 토큰 검증을 가동하여, 이미 완료된 `QuizAttempt`에 대해 브라우저 뒤로가기를 눌러 답변 선택을 바꾼 뒤 교묘히 재제출하려는 우회 어택을 POST 처리 로직 단에서 엄격히 검출 및 원천 차단/무효화 처리합니다.
    *   **백엔드 채점 알고리즘:**
        ```python
        # 1. 시도 기록 생성 (QuizAttempt)
        attempt = QuizAttempt.objects.create(
            user_profile=request.user.userprofile,
            curriculum_id=curr_id,
            score=0
        )
        
        # 2. 문항별 배점 정의
        DIFFICULTY_SCORES = {
            'Easy': 15,
            'Medium': 20,
            'Hard': 30
        }
        
        final_score = 0
        user_answers = request.POST.getlist('answers') # 각 질문별 유저 선택 choice_id 리스트
        
        # 3. 문항 채점 및 오답 테이블(UserResponse) 저장
        for question_id, choice_id in zip(question_ids, user_answers):
            question = QuizQuestion.objects.get(id=question_id)
            choice = QuizChoice.objects.get(id=choice_id)
            is_correct = choice.is_correct
            
            if is_correct:
                # 난이도별 가중 점수 누적
                final_score += DIFFICULTY_SCORES.get(question.difficulty, 0)
                
            UserResponse.objects.create(
                quiz_attempt=attempt,
                question=question,
                selected_choice=choice,
                is_correct=is_correct
            )
            
        # 4. 획득 최종 점수 업데이트 및 저장
        attempt.score = final_score
        attempt.save()
        
        # 5. 마스터리 획득 충족 검증 (70점 이상 시 'completed' 달성)
        if final_score >= 70:
            progress = UserCurriculumProgress.objects.get(
                user_profile=request.user.userprofile,
                curriculum_id=curr_id
            )
            progress.status = 'completed'
            progress.progress = 100
            progress.save()
            
        return redirect('quiz_result', attempt_id=attempt.id)
        ```
