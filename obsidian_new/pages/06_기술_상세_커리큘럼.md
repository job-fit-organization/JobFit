## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/skills/<int:skill_id>/`
*   **장고 뷰 명칭:** `SkillDetailView`
*   **매핑 템플릿:** `skill_detail.html`
*   **Context 데이터:**
    *   `skill`: 상세 조회한 `Skill` 레코드
    *   `curriculums`: 해당 `Skill`과 연계된 `Curriculum` 목록 및 유저별 진행도(`progress`, `status`)가 주입된 목록
        ```python
        # 백엔드 데이터 결합 로직 예시
        curriculum_list = Curriculum.objects.filter(skill_id=skill_id).order_by('step_number')
        enriched_curriculums = []
        
        for curr in curriculum_list:
            progress_record = UserCurriculumProgress.objects.filter(
                user_profile=request.user.userprofile,
                curriculum=curr
            ).first()
            
            enriched_curriculums.append({
                'id': curr.id,
                'step_number': curr.step_number,
                'step_title': curr.step_title,
                'topic': curr.topic,
                'status': progress_record.status if progress_record else 'not_started',
                'progress': progress_record.progress if progress_record else 0
            })
        ```
    *   **선행 학습 잠금 검증 (TC-LOCK-01 방어 설계):**
        *   본 뷰 진입 시 백엔드 `SkillDetailView`가 사용자의 진도 데이터를 검증합니다.
        *   해당 기술에 선행 의존 기술(Prerequisite Skill)이 존재하고, 해당 선행 기술 전체의 `UserCurriculumProgress` 상태가 `completed`가 아닌 경우, 직접 주소창을 통한 상세 페이지 우회 진입을 즉시 차단합니다.
        *   차단 시 유저에게 "선행 기술인 'XXX'을 먼저 완료하셔야 학습을 진행할 수 있습니다."라는 경고 피드백을 세션 메시지로 주입하고, **[04. 직무 로드맵]** 화면으로 강제 리다이렉트시킵니다.
