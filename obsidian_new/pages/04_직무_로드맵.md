## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/jobs/<int:job_id>/roadmap/`
*   **장고 뷰 명칭:** `JobRoadmapView`
*   **매핑 템플릿:** `job_roadmap.html`
*   **Context 데이터:**
    *   `job`: 해당 `Job` 레코드
    *   `roadmap_nodes`: 직무에 소속된 기술 리스트 및 선행 의존성, 사용자 완료 여부 정보가 통합된 리스트
        ```python
        # 백엔드 데이터 가공 예시
        nodes = []
        roadmap_items = Roadmap.objects.filter(job_id=job_id)
        for item in roadmap_items:
            progress = UserCurriculumProgress.objects.filter(
                user_profile=request.user.userprofile,
                curriculum__skill=item.skill
            )
            # 완료/진행 여부 산출
            status = 'not_started'
            if progress.exists():
                status = 'completed' if all(p.status == 'completed' for p in progress) else 'in_progress'
            
            nodes.append({
                'skill_id': item.skill.id,
                'skill_name': item.skill.skill_name,
                'skill_icon_code': item.skill.skill_icon_code,
                'prerequisite_skill_id': item.prerequisite_skill_id, # 선행 기술 ID (NULL이면 시작점)
                'status': status
            })
        ```
    *   **방어적 설계 데이터 가공 규칙 (TC-ROAD-01 & 02):**
        *   **순환 의존성(Cycle Detection) 방어:** 백엔드 가공 시 깊이 우선 탐색(DFS) 기반 순환 구조 검출 코드를 가동하여, DB에 순환 참조 데이터가 존재하더라도 시스템 무한 루프 다운을 차단하고, 충돌 관계 간선을 배제한 안전 렌더링을 보장합니다.
        *   **유실 선행기술(Orphan Node) 승격:** 해당 직무에 매핑되지 않은 유실된 선행 기술 ID를 가리키는 노드는 간선(Edge) 연결을 생략하고 자동으로 해당 캔버스의 독립 시작 루트(Root) 노드로 승격하여 렌더링 크래시를 전격 예방합니다.

## 5. 자바스크립트 라이브러리(Vis.js - Vis-Network) 기반 DAG 드로잉 사양

복잡한 DAG 그래프 구조(다중 시작점, 복수 선행 링크)를 수동 좌표 계산 없이 유연하고 미려하게 렌더링하기 위해, 최적의 위상 정렬 및 계층형 배치(Hierarchical Layout)를 지원하는 전문 시각화 라이브러리인 **Vis.js (Vis-Network)**를 사용합니다.

### 🔌 라이브러리 연동 흐름

1.  **초경량 CDN 로드 (`base.html` 혹은 `job_roadmap.html` 상단):**
    ```html
    <script type="text/javascript" src="https://unpkg.com/vis-network/standalone/umd/vis-network.min.js"></script>
    ```

2.  **안전한 데이터 바인딩 (`job_roadmap.html` 내부 JSON):**
    Django 뷰에서 생성한 노드(Nodes)와 선행 관계 간선(Edges) 데이터를 HTML 내부의 안전한 JSON 블록으로 렌더링합니다.
    ```html
    <script id="roadmap-data" type="application/json">
      {
        "nodes": [
          {"id": 1, "label": "Python", "shape": "circularImage", "image": "https://...", "size": 30, "color": {"border": "#009a93", "background": "#ffffff"}, "borderWidth": 3},
          {"id": 2, "label": "SQL", "shape": "circularImage", "image": "https://...", "size": 30, "color": {"border": "#f47725", "background": "#ffffff"}, "borderWidth": 3},
          {"id": 3, "label": "Pandas", "shape": "circularImage", "image": "https://...", "size": 30, "color": {"border": "#cccccc", "background": "#ffffff"}, "borderWidth": 1}
        ],
        "edges": [
          {"from": 1, "to": 3, "arrows": "to", "color": {"color": "#009a93", "inherit": false}}
        ]
      }
    </script>
    ```

3.  **Vis.js 네트워크 엔진 기동 (`app.js`):**
    ```javascript
    document.addEventListener("DOMContentLoaded", function () {
      const dataElement = document.getElementById("roadmap-data");
      if (!dataElement) return;

      const roadmapData = JSON.parse(dataElement.textContent);
      const container = document.getElementById("roadmap-canvas");

      const data = {
        nodes: new vis.DataSet(roadmapData.nodes),
        edges: new vis.DataSet(roadmapData.edges)
      };

      const options = {
        nodes: {
          borderWidth: 2,
          font: { color: "#1a1a1a", face: "sans-serif", size: 14, bold: true }
        },
        edges: {
          width: 2,
          smooth: { type: "cubicBezier", forceDirection: "vertical", roundness: 0.5 }
        },
        layout: {
          hierarchical: {
            direction: "UD",            // Up-Down 계층형 배치
            sortMethod: "directed",     // DAG 위상 정렬 기반 배치법 적용
            nodeSpacing: 180,           // 노드 간 가로 간격
            levelSeparation: 150        // 계층 간 세로 간격
          }
        },
        interaction: {
          zoomView: true,               // 마우스 휠 확대/축소 가능
          dragView: true                // 드래그앤드롭 화면 이동 가능
        },
        physics: false                  // 노드가 날아다니지 않도록 고정
      };

      const network = new vis.Network(container, data, options);

      // 4. 노드 클릭 시 기술 상세 페이지 이동 연동
      network.on("click", function (params) {
        if (params.nodes.length > 0) {
          const skillId = params.nodes[0];
          window.location.href = `/skills/${skillId}/`;
        }
      });
    });
    ```

### 🏆 자바스크립트 라이브러리 도입의 효과
*   **완벽한 다중 시작점 레이아웃:** Python과 SQL 같이 선행 조건(`from`)이 지정되지 않은 노드들은 계층 구조의 최상단 레벨(Level 0)에 자동으로 예쁘게 병렬 정렬됩니다.
*   **매우 미려한 곡선(Bezier Line):** 수동 SVG 드로잉을 할 필요 없이 큐빅 베지어 곡선이 연결선을 물 흐르듯 유려하게 그려줍니다.
*   **프리미엄 반응형 노드:** 사용자가 노드를 마우스 호버할 때의 확대 효과, 마우스 휠 줌인/줌아웃, 그리고 터치 스와이프 모바일 드래그까지 별도 코딩 없이 완벽하게 제공됩니다.
