## 4. 백엔드 연동 사양 (Django View)

*   **URL 패턴:** `/jobs/`
*   **장고 뷰 명칭:** `JobListView`
*   **매핑 템플릿:** `job_select.html`
*   **Context 데이터:**
    *   `jobs`: DB `Job` 테이블의 전체 리스트 (id, job_code, job_name, job_desc, job_image_url 포함)
*   **POST 요청 처리 (직무 등록):**
    *   사용자가 특정 직무를 클릭하고 완료를 누르면, `JobListView`의 `post()` 메소드(또는 별도 폼 제출)가 동작합니다.
    *   **로직:**
        ```python
        # UserSelectedJob에 저장 혹은 업데이트
        selected_job, created = UserSelectedJob.objects.update_or_create(
            user_profile=request.user.userprofile,
            defaults={'job_id': request.POST.get('job_id')}
        )
        return redirect('job_roadmap', job_id=selected_job.job_id)
        ```
