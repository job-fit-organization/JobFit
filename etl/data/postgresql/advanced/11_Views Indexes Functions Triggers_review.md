# 검수 결과 — 경력자 강의자료
> Step 11: Views, Indexes, Functions, Triggers

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 주제 개요와 예제 수준은 맞고, 코드도 문법적으로 큰 오류는 없어 보입니다. 다만 일부 용어/설명에서 정확성이 떨어지거나(예: 뷰/물질화 뷰 용어 사용), Triggers 예제의 실제 실행 가능성이 의존관계(대상 함수 생성 등) 측면에서 불완전합니다.

**지적 사항** (있는 경우만):
- **Views 성능 최적화 설명이 부정확/불완전**: “물리적 뷰 vs 물질화된 뷰”에서 물리적 뷰가 “매번 쿼리 실행”이라고 단정하지만, 핵심은 일반(일반) 뷰는 **저장된 결과가 없어서** 쿼리 시점에 **실행 계획에 따라 펼쳐진다**는 점입니다(표현이 다소 오해 소지).
- **Triggers 예제의 완전성 부족**: `update_timestamp` 트리거 예제는 `update_modified_column()` 함수가 **이미 존재**해야 실행됩니다. 강의자료 내에서 해당 함수 정의가 없어서 그대로 복사 실행 시 실패할 수 있습니다.
- **Trigger 문법 용어 최신성 이슈 가능**: `EXECUTE PROCEDURE`는 동작하지만, 현재 PostgreSQL에서는 보통 `EXECUTE FUNCTION`을 더 권장/확인 가능한 형태로 다룹니다(환경/버전에 따라 경고 또는 불일치 가능).
