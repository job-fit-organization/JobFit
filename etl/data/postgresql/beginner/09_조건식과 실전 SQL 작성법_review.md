# 검수 결과 — 초급자 강의자료
> Step 9: 조건식과 실전 SQL 작성법

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 CASE/COALESCE/NULLIF/CAST 설명과 예제의 방향은 맞고, 초급 학습목표를 달성하는 데 큰 장애는 없습니다. 다만 초급자 관점에서 조건식/NULL 처리의 문장 몇 군데가 지나치게 일반적이거나(예: NULL이 “결과에 영향을” 미친다), 실습 예제가 데이터 스키마/컬럼 존재 여부에 대한 가정이 있어 학습 불확실성이 있습니다.

**지적 사항** (있는 경우만):
- 슬라이드 3의 “NULL이 포함된 데이터는 결과에 영향을 미칠 수 있습니다”는 사실이지만 너무 포괄적이라 초급자가 구체적으로 어떤 연산/조건에서 어떻게 달라지는지 감을 잡기 어렵습니다(예: `WHERE col = NULL` 문제, 집계 시 동작 등).
- 슬라이드 8 예제는 `students.score`, `students.phone` 같은 컬럼/테이블 구조를 전제하나, 강의자료에 스키마나 예시 데이터 설명이 없어 처음 배우는 학생이 바로 실행하기 어렵습니다.
