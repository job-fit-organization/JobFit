# 검수 결과 — 초급자 강의자료
> Step 1: PostgreSQL 시작하기: 설치, 접속, 샘플 DB 구성

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적인 흐름(설치→접속→샘플DB→SELECT/WHERE/ORDER/INSERT)은 초급자에게 적절하며 코드도 대부분 올바릅니다. 다만 샘플 DB 로드의 경로/권한에 대한 전제가 없어 실행 가능성이 약간 떨어지고, “active = true” 같은 컬럼 존재 여부는 dvdrental 스키마와 직접적인 연결 설명이 부족합니다.

**지적 사항**:
- 샘플 DB 로드: `\i /path/to/dvdrental.sql`에서 실제 파일이 어디에 있고 어떤 경로로 제공되는지(또는 어떤 방법으로 받는지) 설명이 없어 그대로 따라 하면 막힐 수 있습니다.
- 예시 쿼리: `WHERE country = 'USA' AND active = true`에서 `customers` 테이블에 `active` 컬럼이 존재한다는 보장이 없는데, dvdrental 기본 스키마 기준으로 확인/설명 없이 제시되어 오개념 또는 실행 오류 가능성이 있습니다.
