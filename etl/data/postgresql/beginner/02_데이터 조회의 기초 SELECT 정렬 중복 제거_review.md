# 검수 결과 — 초급자 강의자료
> Step 2: 데이터 조회의 기초: SELECT, 정렬, 중복 제거

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 SELECT, 별칭, ORDER BY, DISTINCT, WHERE 사용 예제는 맞고 학습목표 달성이 가능합니다. 다만 6~7장의 설명 범위가 초급 기준에서 약간 단정적이며, WHERE 절 예시/문장 표현이 일부 오해 소지가 있습니다(특히 AND/OR 관련). 또한 강의 초기에 “단일 테이블”임을 강조했지만, `SELECT *` 예시가 학습목표(필요 컬럼 조회)와 약간 어긋날 수 있습니다.

**지적 사항** (있는 경우만):
- **WHERE 절 설명의 일반화**: `WHERE condition`이라고만 제시되어 있는데, 초급자에게는 “condition은 boolean 평가(비교 연산/논리 연산 포함)”이라는 점이 명확히 보강되면 더 안전합니다(현재는 예시는 있으나 설명이 다소 포괄적).
- **AND/OR 예시의 단일 조건 표현**: `SELECT * ...` 예시가 “필요 컬럼만 조회” 목표와는 다소 어긋납니다(오류는 아니지만 학습 목표 관점에서 경미한 불일치).
- **대상 SQL DB 가정**: PostgreSQL 기준 링크를 제공하지만, 전체 내용은 대부분 표준 SQL이라 큰 문제는 없으나 “PostgreSQL에서 동일” 같은 명시가 없어 초급자가 혼동할 여지가 약간 있습니다.
