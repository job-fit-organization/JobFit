## 🟢 초급 문제

### Q1. INSERT 문은 무엇을 수행하는가?
1) 데이터베이스에서 데이터를 삭제한다.
2) 데이터베이스에 새로운 데이터를 추가한다.
3) 데이터베이스의 기존 데이터를 수정한다.
4) 데이터베이스에서 데이터를 조회한다.

<details><summary>정답 보기</summary>

정답: 2번 — INSERT 문은 데이터베이스에 새로운 데이터를 추가하는 SQL 명령어이다.

</details>

### Q2. 트랜잭션의 주요 목적은 무엇인가?
1) 데이터베이스의 데이터를 삭제하기 위해
2) 데이터의 무결성을 보장하기 위해 여러 작업을 하나의 단위로 묶기 위해
3) 데이터베이스의 성능을 높이기 위해
4) 사용자에게 데이터를 조회할 수 있는 권한을 주기 위해

<details><summary>정답 보기</summary>

정답: 2번 — 트랜잭션은 여러 작업을 하나의 단위로 묶어 데이터의 무결성을 보장하기 위해 사용된다.

</details>

## 🟡 중급 문제

### Q3. 다음 중 UPDATE 문으로 데이터를 수정할 때 사용할 수 있는 구문은 어떤 것인가?
1) `UPDATE table_name SET column1 = value1 WHERE condition;`
2) `INSERT INTO table_name VALUES (value1, value2);`
3) `DELETE FROM table_name WHERE condition;`
4) `SELECT * FROM table_name;`

<details><summary>정답 보기</summary>

정답: 1번 — UPDATE 문은 주어진 조건에 맞는 데이터의 특정 컬럼을 수정하는 데 사용된다.

</details>

### Q4. UPSERT의 기능은 무엇인가?
1) 데이터베이스에서 특정 데이터를 업데이트하거나 삭제하는 것
2) 존재하지 않을 경우 데이터베이스에 데이터를 추가하고, 이미 존재할 경우 데이터를 업데이트하는 것
3) 데이터베이스에서 데이터를 조회하는 것
4) 데이터베이스의 모든 데이터를 삭제하는 것

<details><summary>정답 보기</summary>

정답: 2번 — UPSERT는 특정 데이터가 존재하지 않을 경우 추가하고, 존재할 경우 업데이트하는 기능을 제공한다.

</details>

### Q5. ROLLBACK 문은 어떤 역할을 하는가?
1) 변경된 데이터를 영구적으로 저장한다.
2) 특정 트랜잭션에서의 변경 사항을 취소한다.
3) 데이터베이스에서 데이터를 삭제한다.
4) 새로운 트랜잭션을 시작한다.

<details><summary>정답 보기</summary>

정답: 2번 — ROLLBACK 문은 트랜잭션에서 발생한 변경 사항을 취소하고 이전 상태로 되돌린다.

</details>

### Q6. MERGE 문은 어떤 상황에서 사용되는가?
1) 특정 조건에 따라 데이터를 삽입, 업데이트 또는 삭제할 때
2) 데이터베이스의 모든 데이터를 조회할 때
3) 데이터베이스의 스키마를 변경할 때
4) 데이터베이스의 백업을 만들 때

<details><summary>정답 보기</summary>

정답: 1번 — MERGE 문은 특정 조건에 따라 데이터베이스에 데이터를 삽입, 업데이트 또는 삭제하는 데 사용된다.

</details>

## 🔴 고급 문제

### Q7. 트랜잭션을 사용할 때의 주요 장점은 무엇인가?
1) 데이터베이스의 성능을 향상시킨다.
2) 여러 작업을 동시에 처리할 수 있다.
3) 데이터의 일관성을 보장하고 오류 발생 시 이전 상태로 복구할 수 있다.
4) 데이터베이스의 크기를 줄일 수 있다.

<details><summary>정답 보기</summary>

정답: 3번 — 트랜잭션은 데이터의 일관성을 보장하고 오류 발생 시 이전 상태로 복구할 수 있는 기능을 제공한다.

</details>

### Q8. 트랜잭션의 ACID 속성 중 'Isolation'의 의미는 무엇인가?
1) 트랜잭션이 완료되기 전까지 다른 트랜잭션이 접근할 수 없음을 보장한다.
2) 트랜잭션이 완전히 성공하거나 실패해야 함을 보장한다.
3) 트랜잭션의 결과가 영구적으로 저장됨을 보장한다.
4) 트랜잭션이 데이터베이스의 상태를 일관되게 유지해야 함을 보장한다.

<details><summary>정답 보기</summary>

정답: 1번 — Isolation은 트랜잭션이 완료되기 전까지 다른 트랜잭션이 해당 데이터를 접근할 수 없도록 하는 속성을 의미한다.

</details>
