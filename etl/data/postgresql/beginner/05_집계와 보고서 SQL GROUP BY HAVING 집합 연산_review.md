# 검수 결과 — 초급자 강의자료
> Step 5: 집계와 보고서 SQL: GROUP BY, HAVING, 집합 연산

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 개념 정의와 SQL 예시는 맞고 학습 흐름도 자연스럽습니다. 다만 초급자에게는 `GROUP BY GROUPING SETS`, `CUBE/ROLLUP`의 의미가 간단히만 제시되어 있어 학습목표 달성에 필요한 핵심 포인트(결과에서 NULL/그룹요약 행이 의미하는 바 등) 설명이 부족합니다.

**지적 사항** (있는 경우만):
- `GROUPING SETS`, `CUBE`, `ROLLUP` 예제/설명에서 결과에 포함되는 “요약 행”이 어떻게 나타나는지(예: 요약 수준에서 컬럼이 `NULL`로 표시되는 경우가 일반적)와 `GROUPING()` 같은 확인 방법이 언급되지 않아 초급자 오해 가능성이 있습니다.
- `UNION`의 “중복 제거”는 맞지만, 초급자 관점에서 `UNION` vs `UNION ALL` 차이가 비교 없이 생략되어 선택 기준을 이해하기 어렵습니다.
