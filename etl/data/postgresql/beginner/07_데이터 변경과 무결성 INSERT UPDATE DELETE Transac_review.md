# 검수 결과 — 초급자 강의자료
> Step 7: 데이터 변경과 무결성: INSERT, UPDATE, DELETE, Transaction

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 INSERT/UPDATE/DELETE, UPSERT, 트랜잭션(BEGIN/COMMIT/ROLLBACK) 개념과 SQL 예제는 대체로 정확합니다. 다만 트랜잭션·ACID의 설명이 다소 개념적으로만 제시되어 초급자가 실제 무결성(제약조건)과의 연결을 충분히 이해하기엔 부족합니다.

**지적 사항**:
- **학습 목표(“데이터 변경과 무결성”) 대비 설명 부족**: 무결성(예: PK/UNIQUE/FK/NOT NULL 제약조건, CHECK 제약조건)과 INSERT/UPDATE/DELETE/트랜잭션이 무결성에 어떻게 영향을 주는지 구체 예시가 없습니다.
- **트랜잭션의 격리(Isolation)와 실제 동작 설명 부족**: 슬라이드에 ACID는 열거만 있고, 초급자가 “트랜잭션 간 간섭 없음”을 현실적으로 이해할 근거/예시가 없습니다.
- **UPSERT 예시의 ‘열2 = 새로운값’ 표현 측면**: `EXCLUDED.balance`는 정확하지만, “새로운값”이 무엇을 의미하는지(충돌 시 새로 시도한 값) 문장으로 더 명확히 연결하면 더 좋습니다. (코드 자체 오류는 아님)
