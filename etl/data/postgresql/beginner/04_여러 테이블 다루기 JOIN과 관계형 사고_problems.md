## 🟢 초급 문제

### Q1. SQL에서 JOIN의 주된 목적은 무엇인가요?
1) 데이터베이스를 삭제하기 위해
2) 여러 테이블에서 관련된 데이터를 결합하기 위해
3) 데이터베이스의 크기를 줄이기 위해
4) 데이터베이스의 보안을 강화하기 위해

<details><summary>정답 보기</summary>

정답: 2번 — JOIN은 여러 테이블에서 관련된 데이터를 결합하여 조회하기 위해 사용됩니다.

</details>

### Q2. INNER JOIN은 어떤 경우에 사용되나요?
1) 두 테이블 간의 모든 데이터를 조합할 때
2) 한 테이블의 모든 데이터를 가져오고 다른 테이블에서는 일치하는 데이터만 가져올 때
3) 두 테이블 간의 일치하지 않는 데이터를 가져올 때
4) 두 테이블 간의 모든 일치하는 데이터를 가져올 때

<details><summary>정답 보기</summary>

정답: 4번 — INNER JOIN은 두 테이블 간의 모든 일치하는 데이터를 가져오는 데 사용됩니다.

</details>

## 🟡 중급 문제

### Q3. LEFT JOIN을 사용하면 어떤 결과가 나오나요?
1) 오른쪽 테이블의 모든 행이 포함된다.
2) 왼쪽 테이블의 모든 행과 일치하는 오른쪽 테이블의 행이 포함된다.
3) 왼쪽 테이블의 일치하지 않는 행만 포함된다.
4) 두 테이블의 모든 행이 포함된다.

<details><summary>정답 보기</summary>

정답: 2번 — LEFT JOIN은 왼쪽 테이블의 모든 행과 일치하는 오른쪽 테이블의 행을 포함합니다.

</details>

### Q4. 다음 SQL 쿼리에서 SELF JOIN의 목적은 무엇인가요?
```sql
SELECT a.name, b.name
FROM employees a, employees b
WHERE a.manager_id = b.id;
```
1) 모든 직원의 이름을 가져오기 위해
2) 각 직원의 매니저의 이름을 가져오기 위해
3) 매니저가 없는 직원의 이름을 가져오기 위해
4) 직원과 매니저의 관계를 없애기 위해

<details><summary>정답 보기</summary>

정답: 2번 — SELF JOIN은 각 직원의 매니저의 이름을 가져오는 데 사용됩니다.

</details>

### Q5. FULL OUTER JOIN을 사용할 때의 특징은 무엇인가요?
1) 왼쪽 테이블의 모든 행만 가져온다.
2) 오른쪽 테이블의 모든 행만 가져온다.
3) 두 테이블의 모든 행을 가져오며, 일치하지 않는 경우 NULL로 채운다.
4) 두 테이블의 일치하는 행만 가져온다.

<details><summary>정답 보기</summary>

정답: 3번 — FULL OUTER JOIN은 두 테이블의 모든 행을 가져오며, 일치하지 않는 경우 NULL로 채웁니다.

</details>

### Q6. CROSS JOIN의 결과는 무엇인가요?
1) 두 테이블의 일치하는 행을 가져온다.
2) 두 테이블의 모든 조합을 가져온다.
3) 두 테이블 간의 일치하지 않는 데이터를 가져온다.
4) 하나의 테이블에서만 데이터를 가져온다.

<details><summary>정답 보기</summary>

정답: 2번 — CROSS JOIN은 두 테이블의 모든 조합을 가져오는 데 사용됩니다.

</details>

## 🔴 고급 문제

3) 모든 SELECT 쿼리에 DISTINCT를 추가하기
4) JOIN을 사용하지 않고 서브쿼리만 사용하기

<details><summary>정답 보기</summary>

정답: 2번 — 인덱스를 사용하여 자주 조회되는 열에 대해 성능을 향상시키는 것이 JOIN 성능 최적화에 도움이 됩니다.

</details>

### Q8. NATURAL JOIN을 사용할 때 주의해야 할 점은 무엇인가요?
1) 모든 열이 일치해야 한다.
2) 공통 열의 데이터 타입이 동일해야 한다.
3) 공통 열이 여러 개 있을 경우 예기치 않은 결과를 초래할 수 있다.
4) JOIN에 사용된 테이블이 반드시 같은 데이터베이스에 있어야 한다.

<details><summary>정답 보기</summary>

정답: 3번 — NATURAL JOIN은 공통 열이 여러 개 있을 경우 예기치 않은 결과를 초래할 수 있으므로 주의해야 합니다.

</details>
