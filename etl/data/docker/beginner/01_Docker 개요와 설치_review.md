# 검수 결과 — 초급자 강의자료
> Step 1: Docker 개요와 설치

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 초급자에게 Docker 개념과 흐름을 소개하는 데 큰 오류는 없습니다. 다만 몇몇 설명이 사실상 정확하지만 용어 수준에서 오해 소지가 있고, 설치/실행 확인 단계의 명령 사용이 환경에 따라 미묘하게 부정확할 수 있습니다.

**지적 사항** (있는 경우만):
- `sudo docker run hello-world`는 일반적으로 동작하지만, **hello-world 이미지 이름이 “hello-world”로 자동 참조되는 방식**이라 환경/네트워크 상태에 따라 혼동이 생길 수 있습니다(초급자에겐 `docker run hello-world`와 `docker pull`의 관계를 더 명확히 해주면 좋음).
- “컨테이너는 여러 컨테이너가 **동일한 호스트 OS를 공유하지만 서로 격리**”는 취지로는 맞지만, 초급자에게는 “호스트 OS 공유”가 **커널 공유(리눅스 커널)** 관점이 더 명확해야 오해를 줄일 수 있습니다(예: Windows/Mac 환경에서는 별도 런타임/가상화 계층이 있음).
- Docker 설치에서 `docker.io` 패키지 사용은 가능하지만, 최근에는 Docker 공식 권장 방식이 `docker-ce`(공식 Docker 저장소)인 경우가 많아 **설치 결과/버전 차이**를 초급자에게 언급하지 않아 학습 혼선을 줄 수 있습니다.
