# 검수 결과 — 초급자 강의자료
> Step 6: 멀티 컨테이너 환경과 Docker Compose

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 초급자가 “Docker Compose로 멀티 컨테이너를 정의하고 실행한다”는 학습목표를 달성하기에 큰 틀은 맞습니다. 다만 Compose/명령/버전에 대한 일부 설명이 현재 생태계와 불일치하거나 불완전해 학습 혼동을 줄 수 있습니다.

**지적 사항**:
- **슬라이드 6(설치/명령 관련) 부정확성**: Linux에 `pip install docker-compose`로 설치한다고 했는데, 최신 환경에서는 Compose V2가 기본이며 `docker compose`(플러그인) 사용이 일반적이라 오안내 소지가 큽니다. 또한 `docker-compose up/down`만 전제로 설명하면 버전에 따라 동작/사용법이 달라질 수 있습니다.
- **슬라이드 4(Compose 버전 표기) 불완전/구식 가능성**: `version: '3.8'`를 기본으로 제시하지만, Compose V2에서는 버전 필드가 사실상 무의미해지거나 생략 가능해 학습 시 혼동이 있을 수 있습니다(오류라기보다 시대에 맞지 않는 표현).
- **슬라이드 5 예제의 실질적 불완전성**: `app`(Node.js)와 `db`(PostgreSQL)는 구성되어도, `ports`(노출), `depends_on`, 네트워크/환경변수(`DATABASE_URL`), 앱 실행 커맨드/볼륨 등 필수 연결 정보가 없어 “동작하는 예제”로 보기엔 설명이 부족합니다.
