# 검수 결과 — 초급자 강의자료
> Step 2: 첫 컨테이너 실행과 기본 명령어

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 초급자 기준에서 큰 사실 오류는 없고, 이미지/컨테이너 및 기본 명령어 흐름도 학습목표 달성에 도움이 됩니다. 다만 설치 명령어가 환경에 따라 부정확할 수 있고, 컨테이너/프로세스 개념 설명이 일부 오해를 유발할 여지가 있습니다.

**지적 사항**:
- **Docker 설치 절차의 불완전함**: `sudo apt-get install docker-ce` 는 보통 Docker 공식 리포지토리 설정을 선행해야 동작합니다(초급자가 따라 했을 때 실패 가능). 최소한 리포지토리 추가/필수 패키지 안내가 필요합니다.
- **컨테이너 정의 표현의 잠재적 오개념**: “컨테이너는 이미지의 실행 인스턴스, 가동 중인 프로세스”라고 했는데, 컨테이너는 단일 프로세스처럼 설명되면 제한적으로 오해될 수 있습니다(일반적으로 PID 1 포함 프로세스 집합/격리된 실행 환경이라는 뉘앙스가 더 안전).
