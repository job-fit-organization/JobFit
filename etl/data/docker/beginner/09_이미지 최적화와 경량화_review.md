# 검수 결과 — 초급자 강의자료
> Step 9: 이미지 최적화와 경량화

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 Docker 이미지 최적화 개념과 예시 구성은 초급자에게 적절하며, 크게 잘못된 내용은 없습니다. 다만 몇 군데 용어/표현이 부정확하거나(특히 레이어 관련), 보안/최적화의 효과 설명이 다소 단순화되어 학습자 오개념 가능성이 있습니다.

**지적 사항** (있는 경우만):
- **슬라이드 3(레이어 최적화)**: “관련 명령어를 하나의 `RUN`으로 결합하여 레이어 수를 줄인다”는 방향은 맞지만, 일반화 표현이라 “레이어 수” 외에도 캐시 동작/변경 범위에 따라 결과가 달라질 수 있음을 더 명확히 하면 좋습니다(오개념 가능성: 단순히 레이어만 줄이면 항상 최적화가 된다고 이해할 수 있음).
- **슬라이드 4(불필요한 패키지 제거)**: `apt-get clean`과 `rm -rf /var/lib/apt/lists/*`를 통해 “이미지 크기 감소”는 타당하나, 슬라이드 문장만 보면 “불필요한 패키지 제거”와 “청소”가 동일한 맥락으로만 읽힐 수 있어 설명이 약간 단순합니다(그래도 코드 자체는 적절).
- **슬라이드 9(최적화 예시)**: `node:14-alpine`은 예시로는 가능하지만, `node:14`는 비교적 오래된 버전이라 최신 실습 기준에서는 혼동/비권장으로 느껴질 수 있습니다(사실 오류는 아님).
