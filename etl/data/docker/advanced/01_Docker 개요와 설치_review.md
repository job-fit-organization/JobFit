# 검수 결과 — 경력자 강의자료
> Step 1: Docker 개요와 설치

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 핵심 개념(컨테이너/VM 차이, 이미지·컨테이너 관계, CLI-데몬 구조, Compose, 이미지 최적화, 보안 관점)은 큰 오류 없이 구성되어 있습니다. 다만 몇 군데 표현이 부정확하거나(Compose/버전, Ubuntu 설치 방식), 최신성·구체성이 부족해 경력자 학습 관점에서 보완 여지가 있습니다.

**지적 사항** (있는 경우만):
- **슬라이드 6 (Compose)**: `docker-compose up` 실행 예시인데, 최신 Docker 환경에서는 `docker compose up`(플러그인 방식)을 더 일반적으로 쓰며 `version: '3'` 표기는 현재는 크게 의미가 없거나 오해 소지가 있습니다.  
- **슬라이드 4 (설치 방식)**: `docker.io` 패키지로 설치하는 예시는 배포판/버전에 따라 Docker 버전이 구형일 수 있어, “Ubuntu 설치”로서의 안내가 약간 불완전합니다(공식 저장소 설치/버전 확인 같은 언급이 없어서).  
- **슬라이드 5 (Dockerfile)**: `node:14-alpine`는 레거시/구버전이라 최신 기준에서는 학습 예제로는 다소 부적절할 수 있습니다(사실 오류는 아니지만 최신성 측면의 문제).
