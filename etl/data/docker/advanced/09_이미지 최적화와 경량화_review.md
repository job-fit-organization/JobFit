# 검수 결과 — 경력자 강의자료
> Step 9: 이미지 최적화와 경량화

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적으로 Docker 이미지 최적화의 방향성과 설명은 타당하며 코어 개념(레이어/다단계 빌드/린터/정리 등)은 학습에 도움이 됩니다. 다만 일부 항목이 부정확하거나(예: purge 예시, 네트워킹 설명 범위), 다소 부족하게 정리되어 경력자 관점에서 학습 목표 달성에 미세한 방해가 있을 수 있습니다.

**지적 사항** (있는 경우만):
- **3. 불필요한 패키지 제거하기**: `apt-get purge -y --auto-remove` 예시만으로는 실제로 무엇을 정리하는지/언제 실행해야 하는지 맥락이 부족합니다. 보통은 `apt-get install` 직후 같은 RUN에서 정리하고, `apt-get update`/패키지 선택 흐름을 함께 보여줘야 오해 가능성이 줄어듭니다. (코드 자체가 틀렸다기보단 설명이 불완전)
- **5. 다단계 빌드 예시**: `COPY . .` 뒤 `go build`에 대한 빌드 캐시/모듈 캐시(`go.mod`, `go.sum` 분리 복사) 같은 핵심 최적화 포인트가 빠져 있어 “최적화 강의”로서 학습 목표 달성에 조금 미흡할 수 있습니다. (사실 오류는 아니나 불완전)
- **8. Docker 네트워킹 최적화**: “최적화”라는 제목 대비 실제로는 네트워크 생성/연결 예시만 있고, 성능/운영 관점의 최적화 기준(예: DNS 설정, 네트워크 드라이버 선택, 포트 매핑/연결 방식 등) 설명이 거의 없습니다. (주제 범위 불완전)
- **5. Dockerfile 예시(버전)**: `golang:1.16`은 매우 오래된 버전이라 현업 학습 관점에서는 부적절할 수 있습니다. (오류는 아니지만 제공 예시의 현실 적합성이 낮음)
