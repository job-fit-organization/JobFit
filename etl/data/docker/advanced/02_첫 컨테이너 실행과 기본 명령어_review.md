# 검수 결과 — 경력자 강의자료
> Step 2: 첫 컨테이너 실행과 기본 명령어

### 검수 결과: ⚠️ 경미한 문제

**종합 의견**: 전반적인 개념(이미지/컨테이너, `run/ps/exec`, 생명주기)은 대체로 맞고 학습 흐름도 자연스럽습니다. 다만 생명주기 설명의 표현이 약간 부정확하고, 보안 예제는 문맥상 오해 소지가 있으며 성능 최적화 트레이드오프도 단정이 다소 거칩니다.

**지적 사항** (있는 경우만):
- **컨테이너 생명주기**: `docker rm`을 “삭제” 단계로 두는 것은 맞지만, 일반적으로 `docker rm`은 “중지된 컨테이너만 삭제 가능” 등 핵심 제약을 함께 안내하는 편이 정확합니다(현재 설명은 불완전).
- **보안 모범 사례 예제**: `--cap-drop=ALL --cap-add=NET_BIND_SERVICE` 조합은 예시로 가능하나, `my_image`/권한 컨텍스트(비루트 실행, 실제 필요한 capability 식별 등) 없이 최소권한 적용을 일반화하기엔 문맥이 부족해 오해 가능성이 있습니다.
- **성능 최적화 트레이드오프**: “레이어 수 증가 → 빌드 시간 증가, 레이어 감소 → 이미지 크기 증가”는 경우에 따라 성립하지만 단정적으로 들릴 수 있어(항상 그렇진 않음) 표현을 완화할 필요가 있습니다.
